Nap schedules by age

Pick your child's age for a typical nap schedule, wake windows, and a sample day, from newborn to 5 years.

  • Newborn (0–6 weeks)4–7 (irregular) naps · wake windows 35–60 minutes
  • 2–3 months4–5 naps · wake windows 60–90 minutes
  • 4–5 months3–4 naps · wake windows 1.5–2.25 hours
  • 6–7 months3 (moving to 2) naps · wake windows 2–2.5 hours
  • 8–10 months2 naps · wake windows 2.5–3.75 hours
  • 11–14 months2 naps · wake windows 3–4 hours
  • 15–18 months1–2 (usually 1) naps · wake windows 4.5–5.5 hours
  • 19–24 months1 naps · wake windows 5–6 hours
  • 2–3 years1 naps · wake windows 5–6 hours
  • 3–5 years0–1 naps · wake windows 5.5–6.5 hours (if napping)
